# Inkwell migration controls

Only the scenario's prompt, mock, declared patch, installed skills and normal harness go to the actor. The maintainer decision identifies which published addresses may retire once current callers reach their new owners and which desk-card bookmark must survive. The support handoff supplies the customer's questions and the printed bookmark. Neither prescribes an answer. The files here belong to the evaluator.

## Replay offline

After the [whole-root checker setup](../../../../../skills/living-project-documentation/references/validators.md#prepare-the-installed-skill), run from the repository root:

```bash
node tools/evaluation/scenarios/migrate-the-engineering-manual-to-okf/controls/replay.mjs "$validator"
```

Replay materializes the actual patched mock, applies each named edit to a separate copy with its original maintainer decision, and prints the temporary workspaces and checker logs for inspection. Every row below must pass the packaged whole-root checker. Each also preserves the receipt. Replay compares published paths and fragments with the original support decision, follows the three source comments in each layout, and checks whether the repaired retry owner retains the rationale seeded in the original manual. The deliberate failures are checked against their expected outcomes. The replay exercises the discovery script with selected and absent inputs and the receipt script with changed and missing bytes.

- **Format only.** Start from the patched mock and ask “Please add OKF metadata to the engineering manual. Keep its text, paths and links as they are.” The `metadata` output satisfies this request. Compare the pages below their new frontmatter with the source. Report the structural pass and the limited scope. The same output fails the original broad request.
- **Staged work.** With the `staged` output, compare two example reports. “In Specifications → Post records I checked history ordering against the revisions query and added the missing tie rule. Neither report repairs the other subjects.
