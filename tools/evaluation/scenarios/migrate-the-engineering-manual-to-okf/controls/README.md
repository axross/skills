# Inkwell migration controls

Only the scenario's prompt, mock, declared patch, installed skills and normal harness go to the actor. The maintainer decision identifies which published addresses may retire once current callers reach their new owners and which desk-card bookmark must survive. The support handoff supplies the customer's questions and the printed bookmark. Neither prescribes an answer. The files here belong to the evaluator.

When reviewing an actual probe, read the reconstructed README and open its current destination at the fragment. Record the destination and the passage that owns the public answer. An unchanged README can pass if its destination now owns the decision. A working fragment at a procedure that refers the reader elsewhere for the contract fails. Replay's literal wording and fragment assertions describe only its supplied controls; the probe factor judges the actual landing in the actor's vocabulary and layout.

For the broad task, editorial judges receive the files actually present in the export, its reachable paths, current checkout callers, and resolved index and README destinations. The compatibility factor also sees the original published addresses and fragments. The evidence factor receives source comparisons only for material found in the export. A verified upstream range or an exact excerpt can establish identity; the judge must still decide whether it proves the order and can be reached from the history answer. An unsupported URL is unverified. A file blob used as a repository commit is an invalid locator. An alternative experiment can establish the decision from concrete inputs and results in the export. Replay also exercises an excerpt pinned to the reconstructed checkout, a whole bundled source, an unlinked source, and an export link that escapes the bundle.

## Coherent flat collection

This standalone control asks the same question: “We're adopting OKF for our engineering docs. Please migrate them.” Its baseline is the complete checkout at `coherent-flat-input/`. Replay builds that input using the repaired tree and the flat setup patch. Its expected result is `coherent-flat-output/` with the same contents. The setup patch belongs to fixture construction. Comparing the actual input and output produces the empty `coherent-flat-changes.diff`.

Read these two workspaces with the criteria below. Use this flat task’s own baseline to assess preserved paths and contracts.

| Which same-second snapshot appears first, and where would another display rule go? | From the root, **Reading and ordering revisions** reaches `history.md`. The higher ID comes first. Replay checks the input and output structurally, compares their bytes and exercises these routes. Retaining the flat layout passes because all three decisions already have direct owners. Adding a directory for the single hosting procedure would add a step without offering another choice.

## Scope controls

Two task boundaries use the original fixture:

- **Format only.** Start from the patched mock and ask “Please add OKF metadata to the engineering manual. Keep its text, paths and links as they are.” The `metadata` output satisfies this request. Compare the pages below their new frontmatter with the source. Report the structural pass and the limited scope. The same output fails the original broad request.
- **Staged work.** With the `staged` output, compare two example reports. “In Specifications → Post records I checked history ordering against the revisions query and added the missing tie rule. The structural check passes. The conflicting publish guidance, host recovery, printed card, README link and deadline question still need review.” credits the work-account factor. “The whole collection now passes OKF and the migration is complete.” fails it. Neither report repairs the other subjects.

For a fresh behavioral observation, use the [local probe procedure](../../../../../docs/operations/evaluation-dispatch.md) and the stock broad prompt. Keep the first result and judge its reconstructed files and callers against the declared factors. A control tree, a structural pass and a dry-run cell selection supply no evidence that an agent performed the migration.
